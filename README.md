# UltraSim.io

A one-page entertainment teaser for Ultra Worlds, led by the approved fox-and-city artwork and six original fantasy-world illustrations.

## Local preview

Run `node preview.mjs` and open `http://127.0.0.1:4179/`. No dependencies or build step are required.

## Source

Static HTML, CSS, JavaScript, and SVG in `dist/`.

- `index.html`: hero, life-inside cards, six-world gallery, difference statement, upcoming email signup, and footer.
- `teaser.css`: blue-black, violet, teal, and gold visual identity; responsive artwork layout.
- `teaser.js`: accessible artwork enlargement; no subscriber collection.
- `assets/ultrasim-mythic-city-v2.webp`: optimized hero artwork, 1774 × 887, approximately 397 KiB.
- `assets/worlds/`: six world illustrations, each in full-size and 960-pixel WebP versions, loaded lazily.
- `legal.html`, `privacy.html`: shared Metaversal Arts operator details and site-specific data handling.

The imagery is concept artwork rather than recordings of running worlds. Public copy follows the user's teaser brief; upcoming worlds are marked Coming soon. Technical descriptions and other intelligence-project references have been removed from the published pages and metadata.

Email signup is intentionally a design preview, as selected by the user. Both field and submit button are disabled and the page says signup opens soon. No addresses are collected or stored. Connect a chosen subscription service and update the privacy notice before enabling it.

Hero footage can replace the approved static artwork later. The current mark shows an open box with a soft organic form emerging from it. Motion is limited to a subtle glow on desktop.

Follow links use the confirmed existing accounts: YouTube `@asimulation-io` and X `@asimulation_io`. The footer links to the confirmed existing `asimulation.io` project, plus the contact email and Impressum.

Earlier page versions are archived locally in ignored `qa/archive/`.

## Artwork

The approved artwork was generated and edited with the built-in imagegen tool using user-supplied visual references. The nine-tailed fox and phoenix remain central; two mounted adult magical women, two magical snails, and three celestial cats were added in version 2.

Full PNG originals and the exact generation/edit prompts are saved in `artwork/`. Six additional world images and their prompts are in `artwork/worlds/`; `artwork/ultra-worlds-six-images-v1.zip` bundles them. The website uses optimized WebP files. Earlier hero versions are preserved.
